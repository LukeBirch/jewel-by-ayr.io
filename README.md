# Jewel by Ayr

Website for **Jewel by Ayr**, a jewellery business website designed to showcase the brand, products, and services.

## Overview

This project is a modern, responsive single-page website built to provide customers with information about Jewel by Ayr and direct them to the external platform where products can be purchased.

## Tech Stack

* **Next.js** — React framework for the website
* **TypeScript** — Type-safe JavaScript
* **Tailwind CSS** — Styling and responsive design
* **React** — UI components
* **Git & GitHub** — Version control and project management
